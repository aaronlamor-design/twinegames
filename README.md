This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

This is a project I created to host [Twine](https://twinery.org) games that i've found and downloaded off the internet. I have not included the games with this project. To play a twine game, just add it as a folder nested in the public folder.
